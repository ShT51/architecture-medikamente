# Оценка Data Encryption at Rest and In Transit

| Данные                           | Пример данных                                        | В чём необходимость защиты                                                                                                                                                     | Инструменты защиты                                                                                                                                                             |
|----------------------------------|------------------------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Персональные данные (PII)        | ФИО, паспорт, телефон, email                         | Штрафы по 152-ФЗ и серьезные репутационные риски в случае утечки                                                                                                               | Data at Rest: шифрование полей в БД (AES-256); Data in Transit: TLS 1.3, HTTPS; Контроль: RBAC (Keycloak), аудит доступа (Splunk + ELK стек)                                   |
| Медицински данные клиентов (PHI) | Диагнозы, анализы, назначения                        | Штрафы по 152-ФЗ и серьезные репутационные риски в случае утечки, риски для жизни и здоровья в случае подмены                                                                  | Data at Rest: шифрование полей в БД (AES-256); Data in Transit: TLS 1.3, HTTPS; Контроль: RBAC (Keycloak), аудит доступа (Splunk + ELK стек)                                   |
| Платежные данные                 | Номера карт, реквизиты счетов                        | Штрафы, уголовная ответственность, серьезные репутационные риски, риск мошеннических действий в случае утечки. <br/>Должны храниться и обрабатываться в соответствии с PCI DSS | Data at Rest: шифрование полей в БД (AES-256); Data in Transit: TLS 1.3, HTTPS; Контроль: RBAC (Keycloak), аудит доступа (Splunk + ELK стек) + аудит на соответствие PCI DSS   |
| Учетные данные                   | Логины, пароли, токены доступа                       | Несанкционированный доступ и компрометация всей системы                                                                                                                        | Data at Rest: шифрование полей в БД (AES-256); Data in Transit: TLS 1.3, HTTPS; Контроль: RBAC (Keycloak) + 2FA, аудит доступа (Splunk + ELK стек); регулярная ротация паролей |
| Внутренняя информация            | Время записи, ID пациента                            | В теории может использоваться для деанонимизации клиентов                                                                                                                      | Data in Transit: TLS 1.3, HTTPS; Контроль: RBAC (Keycloak), аудит доступа (Splunk + ELK стек)                                                                                  |
| Аналитика                        | Агрегированные отчеты, данные для ML и AI-технологий | Может использоваться конкурентами для получения преимуществ на рынке                                                                                                           | Data at Rest: шифрование полей в БД (AES-256); Data in Transit: TLS 1.3, HTTPS; Контроль: RBAC (Keycloak), аудит доступа (Splunk + ELK стек)                                   |
